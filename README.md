# User Authentication & Contact Management API

Developed a RESTful API using Node.js, Express.js, and MongoDB to manage user authentication and contact information securely and efficiently.

The project includes user registration and login functionality with JWT (JSON Web Token) authentication to protect private routes and authorize users. Passwords are securely hashed before being stored in the database to improve account security.

It also provides complete CRUD (Create, Read, Update, and Delete) operations for contact management, allowing users to create new contacts, retrieve contact details, update existing records, and delete contacts through API endpoints.

**Key Features:**
- User registration and login
- JWT-based authentication and protected routes
- Secure password hashing
- Contact CRUD operations
- RESTful API architecture
- MongoDB database integration using Mongoose
- Request handling and JSON responses
- API testing using Postman
- Modular project structure with separate routes and controllers
- Error handling and input validation

**Technologies Used:**
Node.js, Express.js, MongoDB, Mongoose, JSON Web Token (JWT), bcrypt, JavaScript, and Postman.

This project helped me strengthen my backend development skills, understand REST API design, implement authentication and authorization, work with MongoDB, and test API endpoints using Postman.

The project demonstrates my practical knowledge of backend development and provides a foundation for building secure and scalable applications using the MERN stack.
